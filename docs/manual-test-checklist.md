# 手動檢查清單

每次發佈前，用 `publish\TimeZoneCalc\TimeZoneCalc.exe` 逐項確認。

## 啟動與版面
- [ ] 開啟即顯示兩列：`UTC (UTC+00:00)`（藍條）、`台北 (UTC+08:00)`
- [ ] 時間為現在的 UTC 時間，台北列多 8 小時
- [ ] 時區名稱完整顯示，日期時間沒有被截斷
- [ ] 把視窗拉大：數字鍵盤停在最大尺寸並置中，時區按鈕仍與日期時間靠左對齊

## 輸入
- [ ] 開啟後不點任何東西直接打 `143205` → 第一列時間 `14:32:05`，台北列 `22:32:05`
- [ ] 打 `1432` → `14:32:00`
- [ ] 小時十位數打 `3` 沒反應；`2` 之後打 `4` 沒反應
- [ ] 點第一列的日期 → 日期出現底線，打 `20261231` → 日期更新
- [ ] 點第二列的時間 → 藍條移到第二列，打 `160000` → 第一列變成 `08:00:00`
- [ ] `Tab` 切換日期／時間；`↑`／`↓` 切換列
- [ ] 日期打 `20260231` → 日期標紅、上方紅色提示、另一列變灰但保留原值
- [ ] 日期只打 `2026` 就點另一列 → 載入上一個有效時間，不卡住
- [ ] `Backspace`、`Esc`、`N` 與畫面上 ⌫、C、現在 行為一致
- [ ] 用滑鼠點畫面上的數字鍵，時間會跟著變

## 時區
- [ ] 點時區按鈕 → 跳出搜尋面板，游標在搜尋框
- [ ] 打 `tai`、`紐約`、`new york`、`tokyo`、`+07:00` 都找得到
- [ ] 按 Enter 或點選清單項目 → 面板關閉、時區更新；接著直接打數字會輸入到計算器
- [ ] 按 Esc 或點面板外面 → 面板關閉、時區不變；接著直接打數字會輸入到計算器
- [ ] 兩列都能重複換時區，不會卡在選單裡
- [ ] 改另一列的時區 → 同一瞬間換算；改輸入列的時區 → 保留打好的時間

## 夏令時間
- [ ] 第一列設紐約（東部時間），輸入 `20260308` `023000` → 黃色提示「不存在」，另一列 `—`
- [ ] 第一列設紐約，輸入 `20261101` `013000` → 提示「出現兩次」，按「改用第二次」後另一列 +1 小時
- [ ] 第一列 UTC 輸入 `20261101` `063000`，第二列設紐約（顯示 01:30 `UTC-05:00`），點第二列 → 第一列仍是 06:30

## 複製
- [ ] 用滑鼠框選某一列的日期時間，按 `Ctrl+C`，貼上為框選的內容
- [ ] 沒有框選時按 `Ctrl+C`，貼上為輸入列的 `yyyy-MM-dd HH:mm:ss`

## 可攜性
- [ ] 在沒有開發工具的 Win10 或 Win11 電腦解壓 zip、雙擊執行，以上項目抽測正常
