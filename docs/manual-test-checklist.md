# 手動檢查清單

每次發佈前，用 `publish\TimeZoneCalc\TimeZoneCalc.exe` 逐項確認。

## 啟動與版面
- [ ] 開啟即顯示兩列：`UTC (UTC+00:00)`（藍條）、`台北 (UTC+08:00)`
- [ ] 時間為現在的 UTC 時間，台北列多 8 小時
- [ ] 時區名稱完整顯示，日期時間沒有被截斷
- [ ] 把視窗拉大：數字鍵盤停在最大尺寸並置中，時區按鈕仍與日期時間靠左對齊

## 輸入
- [ ] 開啟後不點任何東西直接打 `143205` → 第一列時間 `14:32:05`，台北列 `22:32:05`（時打滿自動跳分、再跳秒）
- [ ] 分別點年、月、日、時、分、秒 → 底線移到點的那一欄，打數字只改那一欄
- [ ] 點第一列的年，連打 `20261231235958` → 一次填完 `2026-12-31 23:59:58`
- [ ] 時打 `30` → `23`；分打 `75` → `59`；秒打 `99` → `59`；月打 `15` → `12`
- [ ] 月設 `06`、日打 `31` → `30`；月設 `02`（2026 年）、日打 `30` → `28`；2024 年 2 月 → `29`
- [ ] 日期是 `03-31` 時把月改成 `02` → 日自動變 `28`
- [ ] 點第二列的時 → 藍條移到第二列，打 `160000` → 第一列跟著換算
- [ ] `Tab`／`→` 下一欄，`Shift+Tab`／`←` 上一欄；`↑`／`↓` 切換列
- [ ] 年只打 `20` 就點另一列 → 載入上一個有效時間，不卡住；年只打 `20` 就按 `Tab` → 年還原成原本的值
- [ ] 按 `+` 加到第 5 列後 `+` 反灰；按 `−` 減到剩 2 列後 `−` 反灰；視窗高度跟著變
- [ ] 新加的列預設 UTC、顯示同一時刻；輸入列在最後一列時按 `−` → 輸入列移到上一列，時間不變
- [ ] 鍵盤 `+`／`−`（含數字鍵區）也能加減列
- [ ] `Backspace`、`Esc`、`N` 與畫面上 ⌫、C、現在 行為一致（⌫／C 只作用在目前欄位）
- [ ] 用滑鼠點畫面上的數字鍵，時間會跟著變

## 時區
- [ ] 點時區按鈕 → 跳出搜尋面板，游標在搜尋框
- [ ] 打 `tai`、`紐約`、`new york`、`tokyo`、`+07:00` 都找得到
- [ ] 按 Enter 或點選清單項目 → 面板關閉、時區更新；接著直接打數字會輸入到計算器
- [ ] 按 Esc 或點面板外面 → 面板關閉、時區不變；接著直接打數字會輸入到計算器
- [ ] 兩列都能重複換時區，不會卡在選單裡
- [ ] 改另一列的時區 → 同一瞬間換算；改輸入列的時區 → 保留打好的時間

## 夏令時間
- [ ] 第一列設紐約（東部時間），從年開始輸入 `20260308023000` → 黃色提示「不存在」，另一列 `—`
- [ ] 第一列設紐約，從年開始輸入 `20261101013000` → 提示「出現兩次」，按「改用第二次」後另一列 +1 小時
- [ ] 第一列 UTC 從年開始輸入 `20261101063000`，第二列設紐約（顯示 01:30 `UTC-05:00`），點第二列 → 第一列仍是 06:30

## 複製
- [ ] 用滑鼠框選某一列的日期時間，按 `Ctrl+C`，貼上為框選的內容
- [ ] 沒有框選時按 `Ctrl+C`，貼上為輸入列的 `yyyy-MM-dd HH:mm:ss`

## 可攜性
- [ ] 在沒有開發工具的 Win10 或 Win11 電腦解壓 zip、雙擊執行，以上項目抽測正常
