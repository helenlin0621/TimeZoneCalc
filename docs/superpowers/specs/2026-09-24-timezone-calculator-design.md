## 1. 目的

查 log 時，需要在「log 寫入時使用的時區」、「發現問題當下所在的時區」，以及偶爾的第三個時區之間換算時間點。本程式是 Windows 桌面工具：輸入一個時區的日期時間，立即看到它在其他時區是幾點。

**不在範圍內**（YAGNI）：
- 貼上 log 字串自動解析（日後可加）
- 計算兩個時間點的間隔
- 毫秒精度
- 記住上次的時區設定

## 3. 技術與發佈

- **語言／框架**：C#、.NET 9、Windows App SDK（WinUI 3）。
- **建置**：以 .NET 9 SDK 指令列 `dotnet build` / `dotnet publish` 建置，不依賴 Visual Studio。
- **發佈型態**：unpackaged，同時設定
  - `WindowsPackageType=None`
  - `WindowsAppSDKSelfContained=true`
  - `SelfContained=true`，`RuntimeIdentifier=win-x64`
- **產出**：一個資料夾（壓成 zip 帶走），解壓後雙擊 `TimeZoneCalc.exe` 執行。目標電腦不需預先安裝 .NET 或 Windows App SDK。
- **不做**單一 exe（WinUI 3 單檔發佈不穩定）、不做 MSIX（需要簽章憑證）。
- **支援平台**：Windows 10 1809（build 17763）以上、Windows 11，x64。
- **預估大小**：約 100–200 MB（實際數字於建置後量測並記錄於 README）。
- **首要風險**：指令列建置 WinUI 3 的工具鏈問題。實作第一步先做最小 Hello World，發佈後在無開發環境的電腦上試跑，通過才繼續。

## 4. 程式結構

三個互相獨立的單元：

### 4.1 換算核心 `TimeZoneCalc.Core`（類別庫，不引用任何 UI）

- **`ZoneOption`**：一個可選的時區。
  - 種類：`City`（包 `TimeZoneInfo`）或 `FixedOffset`（包 `TimeSpan`）。
  - 屬性：`Id`、`DisplayName`。
  - 方法：`GetOffset(DateTime utc)` 回傳該瞬間的偏移量，以及是否為夏令時間。
- **`Converter`**
  - `Resolve(ZoneOption zone, DateTime localWallTime, AmbiguityChoice choice)` → 結果為以下三者之一：
    - `Ok(DateTimeOffset instant)`
    - `Invalid`（該時區不存在此時間）
    - `Ambiguous(first, second)`：依 `choice` 取第一次或第二次出現，同時回報這是重複時間
  - `ToZone(DateTimeOffset instant, ZoneOption zone)` → 該時區的牆上時間與偏移量。
- **`DigitEntry`**：數字由左往右填入的狀態機。
  - 兩種模式：時間 `HHmmss`（6 位）、日期 `yyyyMMdd`（8 位）。
  - `TryPush(digit)`：這一位若會造成不合法的值就拒絕，並回傳 false。
  - `Backspace()`、`Clear()`、`Load(value)`；`Load` 用於切換列時載入現值，之後打下第一個數字會重新開始填。
  - `Value`：未填的位補 0 後的結果；日期未填滿 8 位時視為未完成。

### 4.2 時區清單 `ZoneCatalog`（放在 Core）

排序：
1. `UTC`
2. `台北 (Asia/Taipei)`
3. 固定偏移量 `UTC-12:00` ～ `UTC+14:00`，以 15 分鐘為單位，只列出實際存在的偏移量（含 +05:30、+05:45、+08:45 等）
4. 其餘所有 `TimeZoneInfo.GetSystemTimeZones()` 城市時區，依顯示名稱排序

城市時區使用 Windows 系統時區資料；台北的 Windows ID 為 `Taipei Standard Time`。

### 4.3 畫面 `TimeZoneCalc.App`（WinUI 3）

只負責顯示與輸入，所有計算都呼叫 Core。

## 5. 畫面與操作

```
┌──────────────────────────────────────────┐
│ 時區計算器                          ─ □ ✕ │
├──────────────────────────────────────────┤
│  📅             2026-09-24   14:32:05    │ ← 大字：日期段 + 時間段
│                 ‾‾‾‾‾‾‾‾‾‾               │   目前輸入段有底線
│ ▌UTC             ▾  2026-09-24 06:32:05 ⧉ ✕│
│  台北 (UTC+08:00) ▾ 2026-09-24 14:32:05 ⧉ ✕│
│  ＋ 新增時區                               │
├──────────────────────────────────────────┤
│   [ 現在 ]      [  C  ]      [  ⌫  ]      │
│   [  7  ]      [  8  ]      [  9  ]      │
│   [  4  ]      [  5  ]      [  6  ]      │
│   [  1  ]      [  2  ]      [  3  ]      │
│                [  0  ]                   │
└──────────────────────────────────────────┘
```

### 5.1 輸入列

- 輸入列左側有藍條；點任一列即成為輸入列，大字區載入該列目前的日期時間，其他列以它為基準換算。
- 每列顯示自己的日期（換算後可能跨日、跨月、跨年）。

### 5.2 大字區（日期段 + 時間段）

- 點日期段或時間段，或按 `Tab`，可切換目前輸入段；目前輸入段有底線。
- 數字由左往右填入：
  - 時間：`143205` → `14:32:05`；只打 `1432` → `14:32:00`
  - 日期：`20260924` → `2026-09-24`
- 切到某一段後，打下第一個數字會從頭重新填。
- 拒絕不合法的位數：例如小時 `2` 之後只接受 `0`–`3`，分／秒的十位數只接受 `0`–`5`。
- 日期填滿 8 位時才驗證：不存在的日期（如 `20260231`）或年份超出 1900–2100 時，日期段標紅，其他列暫停換算，維持上一個有效值並顯示為灰色。
- 📅 按鈕開啟月曆（`CalendarView` flyout），選定後關閉，並把日期段設為所選日期。

### 5.3 按鍵

| 畫面按鈕 | 實體鍵盤 | 動作 |
|---|---|---|
| `0`–`9` | `0`–`9`、數字鍵區 | 輸入目前段 |
| `⌫` | `Backspace` | 刪除目前段最後一位 |
| `C` | `Esc` | 目前段清為 `00:00:00`（時間）或今天（日期） |
| `現在` | `N` | 日期與時間都設為現在（以輸入列時區計） |
| — | `Tab` | 在日期段、時間段之間切換 |
| — | `↑` / `↓` | 切換輸入列 |
| 各列 `⧉` | `Ctrl+C` | 複製該列（快捷鍵複製輸入列）為 `yyyy-MM-dd HH:mm:ss` |

時區下拉選單取得焦點時，數字鍵不會被攔截，讓篩選可以正常打字。

### 5.4 時區列

- 時區下拉選單使用可打字篩選的 `AutoSuggestBox` 或可編輯的 `ComboBox`，比對顯示名稱與 ID，不分大小寫。
- 時區名稱旁顯示該列日期當天的實際偏移量，例如「紐約 (UTC-04:00 夏令)」。
- 列數 1–5：只剩 1 列時隱藏 `✕`；已達 5 列時隱藏「＋ 新增時區」。新增的列預設為 UTC。
- 刪除輸入列時，第一列成為輸入列。

## 6. 夏令時間特殊情況

| 情況 | 例子 | 行為 |
|---|---|---|
| 不存在的時間 | 紐約 2026-03-08 02:30 | 輸入列顯示黃色提示「此時間因夏令時間切換而不存在」；其他列顯示 `—` |
| 重複的時間 | 紐約 2026-11-01 01:30 | 預設採第一次出現（夏令時間）；提示「此時間出現兩次」，並提供切換鈕改用第二次出現；換輸入值後選擇重置為第一次 |

固定偏移量與 UTC、台北不會出現上述情況。

## 7. 錯誤處理

- 所有錯誤都顯示在畫面上，不跳對話框、不讓程式當掉。
- 系統找不到 `Taipei Standard Time` 時，改以固定偏移量 `UTC+08:00` 代替，並在該列顯示提示。
- 剪貼簿寫入失敗時，在該列短暫顯示「複製失敗」。

## 8. 測試

- **Core 單元測試（xUnit）**
  - UTC↔台北雙向換算
  - 換算後跨日、跨月、跨年
  - 固定偏移量（含 +05:45）
  - 夏令時間：不存在時間、重複時間，以及兩種選擇
  - `DigitEntry`：部分輸入補 0、拒絕不合法位數、Backspace、Load 後第一個數字重新開始
  - 日期驗證：2/29 閏年與非閏年、年份邊界
  - `ZoneCatalog` 排序：UTC、台北在最前
- **UI 手動檢查清單**：鍵盤、滑鼠、月曆、Tab／↑↓、新增與刪除列、複製、錯誤提示。放在 `docs/manual-test-checklist.md`。
- **發佈驗證**：在無開發環境的 Windows 10 或 11 電腦解壓執行，走一遍檢查清單。
